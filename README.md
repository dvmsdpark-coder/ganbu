# 간부 일정관리 프로토타입

브라우저에서 바로 열 수 있는 1차 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 포함된 기능

- 국별 보기
- 국 목록: 정책기획관실, 국제농식품협력관실, 농촌정책국, 농업정책관실, 농산업혁신정책관실, 농촌소득에너지정책관실, 식품산업정책관실, 동물복지정책국, 식량정책관실, 축산정책관실, 유통소비정책관실, 방역정책국
- Supabase 무료 플랜 연결 준비
- 회원가입, 로그인, 승인 대기
- 총관리자 사용자 승인 및 권한 부여
- 구성원, 국 관리자, 총관리자 권한
- 월간 캘린더
- 주간 일정표
- 장관·차관·실장·국장·과장 일정 색상 구분
- 시간과 일정명 표시: `(09:30) 국정과제 점검회의`
- 국장·과장 일정은 구성원도 등록·수정 가능
- 장관·차관·실장 일정은 관리자만 등록·수정 가능
- 관리자 삭제
- 변경 이력
- 2주 지난 일정은 기본 숨김 처리

## 실제 운영 전환 시 필요한 것

현재 앱에는 Supabase Project URL과 anon key가 기본값으로 들어가 있어서 접속 시 자동으로 Supabase DB에 연결됩니다. 사용자가 연결 버튼을 누르거나 URL/key를 볼 필요는 없습니다. 사용자는 회원가입 후 총관리자 승인을 받아야 접속할 수 있습니다.

Supabase 설정을 바꾸려면 `app.js`의 `DEFAULT_SUPABASE_CONFIG` 값을 수정하면 됩니다. DB 테이블은 `supabase-schema.sql`을 Supabase SQL Editor에서 실행해 만들 수 있습니다.

첫 총관리자 계정은 앱에서 회원가입한 뒤 `SUPABASE_SETUP.md`의 SQL로 한 번만 승인해야 합니다. 이후 가입자는 총관리자가 앱 안에서 승인하고 권한을 부여합니다. 이 앱은 총관리자 승인 절차가 있으므로 Supabase 이메일 확인은 꺼두는 것을 권장합니다.

여러 직원이 접속하려면 이 앱 파일도 공용 위치에 배포해야 합니다. 시험 운영은 내부 공유 서버, GitHub Pages, Cloudflare Pages, Netlify 같은 무료 정적 호스팅으로 시작할 수 있습니다.

운영형 구성 예시는 다음과 같습니다.

- 프론트엔드: 현재 화면을 React 또는 Vue로 전환
- 백엔드: FastAPI, Spring Boot, Node.js 중 기관 표준에 맞게 선택
- 데이터베이스: PostgreSQL, MariaDB, MS SQL Server 중 내부 표준 선택
- 로그인: 기관 SSO 또는 내부 계정
- 권한: 국별 사용자, 국별 관리자, 전체 관리자
- 기록: 모든 등록·수정·삭제 이력 저장
- 보관: 주간 화면은 2주 경과 숨김, 원본 데이터는 감사·복구용으로 보존

서버 비용은 배포 방식에 따라 달라집니다. 내부 서버를 쓰면 별도 클라우드 비용은 줄일 수 있고, 외부 클라우드나 관리형 DB를 쓰면 월 비용이 발생합니다.
